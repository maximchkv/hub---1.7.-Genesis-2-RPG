# Руководство по логике карт

Этот документ описывает все карты игрока, их описание в UI и реальную логику выполнения в боевом цикле.

## Система статусов

Перед описанием карт, важно понять, как работает система статусов:

### Типы статусов

1. **Кровоток (Bleed)**
   - Наносит урон в начале каждого хода (равный количеству стаков)
   - Урон проходит через блок (не является оружейным уроном)
   - Уменьшается на 3 стака каждый ход
   - Применяется в `startOfTurn()` → `applyBleedIfNeeded()`

2. **Слабость (Weak)**
   - Уменьшает исходящий оружейный урон на 25% (×0.75)
   - Учитывается в `modifiedOutgoingWeaponDamage()`
   - Уменьшается на 1 стак каждый ход
   - Применяется в `startOfTurn()` → `decrementDurations()`

3. **Уязвимость (Vulnerable)**
   - Увеличивает входящий оружейный урон на 50% (×1.5)
   - Учитывается в `modifiedDamage()` для входящего урона
   - Уменьшается на 1 стак каждый ход
   - Применяется в `startOfTurn()` → `decrementDurations()`

4. **Оглушение (Stun)**
   - Пропускает следующий ход цели
   - Уменьшается на 1 стак каждый ход
   - Применяется в `startOfTurn()` → `decrementStunIfNeeded()`

### Порядок обработки статусов в начале хода

1. Кровоток применяется первым (урон через блок)
2. Проверка оглушения (если есть - пропуск хода)
3. Уменьшение длительности (Weak/Vulnerable уменьшаются на 1)
4. Очистка статусов с 0 стаками

## Карты игрока

### Базовые карты

#### 1. Мощный удар (Power Strike)
- **Стоимость:** 1 ОД
- **Описание в UI:** "Наносит урон противнику. Базовая атакующая карта."
- **Реальная логика:**
  - Базовый урон = `baseValue(level)` (5 на уровне 1, ×1.25 за каждый уровень)
  - Урон модифицируется через `modifiedOutgoingWeaponDamage()` (учитывает Weak на игроке)
  - Урон применяется через `dealDamage()` (учитывает блок врага и Vulnerable на враге)
  - Лог: `"Power Strike (-1 AP): dmg X (blocked Y)"`
- **Код:** `GameStore.swift:728-736`

#### 2. Защита (Defend)
- **Стоимость:** 1 ОД
- **Описание в UI:** "Даёт блок, защищая от входящего урона."
- **Реальная логика:**
  - Блок = `defendBlock(level)` = `baseValue(level)` (5 на уровне 1, ×1.25 за уровень)
  - Прямое добавление: `battle.playerBlock += bVal`
  - Лог: `"Guard (-1 AP): block +X"`
- **Код:** `GameStore.swift:738-741`

#### 3. Двойной удар (Double Strike)
- **Стоимость:** 2 ОД
- **Описание в UI:** "Наносит урон дважды. Эффективна против блока."
- **Реальная логика:**
  - Урон за удар = `doubleStrikeHit(level)` = `powerStrikeDamage(level) × 0.8`
  - Два отдельных вызова `dealDamage()` (каждый учитывает блок отдельно)
  - Каждый удар модифицируется через `modifiedOutgoingWeaponDamage()` (Weak)
  - Лог: `"Double Strike (-2 AP): dmg X (blocked Y)"` (суммарный урон и блок)
- **Код:** `GameStore.swift:743-753`

#### 4. Контратака (Counter Stance)
- **Стоимость:** 2 ОД
- **Описание в UI:** "Даёт блок и наносит урон одновременно."
- **Реальная логика:**
  - Блок = `counterStanceBlockValue()` = **4** (фиксированное значение)
  - Урон = `counterStanceAttackValue()` = **3** (фиксированное значение)
  - Сначала добавляется блок: `battle.playerBlock += 4`
  - Затем урон через `dealDamage()` (модифицируется Weak/Vulnerable)
  - Лог: `"Counter Stance (-2 AP): block +4, dmg X (blocked Y)"`
- **Код:** `GameStore.swift:755-765`

### Статусные карты

#### 5. Кровоток (Bleed Plus 2)
- **Стоимость:** 1 ОД
- **Описание в UI:** "Накладывает Кровоток +2 на противника. Кровоток наносит урон в начале каждого хода."
- **Реальная логика:**
  - Вызов: `battle.addStatus(.bleed, stacks: 2, to: .enemy)`
  - Добавляет 2 стака Кровотока врагу (или увеличивает существующие)
  - Кровоток нанесет 2 урона в начале следующего хода врага
  - Лог: `"Player uses Кровоток → Enemy: Кровоток +2"`
- **Код:** `GameStore.swift:768-770`

#### 6. Ослабить (Weak Plus 1)
- **Стоимость:** 1 ОД
- **Описание в UI:** "Накладывает Слабость +1 на противника. Слабость уменьшает наносимый урон."
- **Реальная логика:**
  - Вызов: `battle.addStatus(.weak, stacks: 1, to: .enemy)`
  - Добавляет 1 стак Слабости врагу
  - Слабость уменьшит исходящий оружейный урон врага на 25% (×0.75)
  - Уменьшается на 1 стак каждый ход врага
  - Лог: `"Player uses Ослабить → Enemy: Слабость +1"`
- **Код:** `GameStore.swift:772-774`

#### 7. Оглушить (Stun 1)
- **Стоимость:** 2 ОД
- **Описание в UI:** "Накладывает Оглушение 1 на противника. Оглушенный пропускает следующий ход."
- **Реальная логика:**
  - Вызов: `battle.addStatus(.stun, stacks: 1, to: .enemy)`
  - Добавляет 1 стак Оглушения врагу
  - Враг пропустит следующий ход (в `startOfTurn()` → `decrementStunIfNeeded()`)
  - Уменьшается на 1 стак после применения
  - Лог: `"Player uses Оглушить → Enemy: Оглушение 1"`
- **Код:** `GameStore.swift:776-778`

### Синергийные карты

#### 8. Кровавый удар (Bleed Strike)
- **Стоимость:** 2 ОД
- **Описание в UI:** "Если у противника есть Кровоток: наносит урон равный стакам Кровотока × 3. Если Кровотока нет: накладывает Кровоток +2. Синергийная карта для тактики кровотечения."
- **Реальная логика:**
  - Проверка: `battle.enemyStatuses.first(where: { $0.type == .bleed })?.stacks ?? 0`
  - **Если у врага есть Кровоток:**
    - Урон = стаки Кровотока × 3
    - Урон через `dealDamage()` (модифицируется Weak/Vulnerable)
    - Лог: `"Кровавый удар (-2 AP): dmg X (blocked Y, от кровотечения ×N)"`
  - **Если Кровотока нет:**
    - Вызов: `battle.addStatus(.bleed, stacks: 2, to: .enemy)`
    - Лог: `"Кровавый удар (-2 AP): Кровоток +2"`
- **Код:** `GameStore.swift:781-796`

#### 9. Ослабляющий щит (Weak Defend)
- **Стоимость:** 2 ОД
- **Описание в UI:** "Накладывает Слабость +1 на противника и даёт Блок +4. Комбинирует контроль и защиту."
- **Реальная логика:**
  - Вызов: `battle.addStatus(.weak, stacks: 1, to: .enemy)` ✅
  - Добавление блока: `battle.playerBlock += 4` ✅
  - Лог: `"Ослабляющий щит (-2 AP): Слабость +1 врагу, блок +4"`
- **Код:** `GameStore.swift:798-801`
- **Примечание:** Логика выглядит корректной. Если эффекты не применяются, возможно проблема в:
  - Отображении статусов в UI
  - Проверке статусов в других частях кода
  - Порядке выполнения операций

## Логика врагов

### Действия врагов

Враги используют те же базовые действия (атака, защита, контратака, двойной удар), что и игрок. Они не имеют отдельной механики наложения статусов при атаке - статусы должны применяться через карты из общей базы карт.

**Код:** `GameStore.swift:862-920`

### Порядок выполнения атаки врага

1. Вычисляется базовый урон
2. Урон модифицируется через `modifiedOutgoingWeaponDamage()` (учитывает Weak на враге)
3. Урон применяется через `dealDamage()` (учитывает блок игрока и Vulnerable на игроке)

### Оглушение врага

Когда враг оглушен:
- Его ход пропускается (не выполняется `performEnemyTurn()`)
- **Паттерн действий продвигается всегда** - это расписание ходов, которое продолжается независимо от оглушения
- Интент обновляется для следующего хода

**Код:** `GameStore.swift:833-844`

## Система уровней карт

### Расчет базовых значений

- **Базовое значение (уровень 1):** 5
- **Формула:** Для каждого уровня выше 1: `value = value × 1.25` (округление)
- **Примеры:**
  - Уровень 1: 5
  - Уровень 2: 6 (5 × 1.25 = 6.25 → 6)
  - Уровень 3: 8 (6 × 1.25 = 7.5 → 8)
  - Уровень 4: 10 (8 × 1.25 = 10)
  - Уровень 5: 13 (10 × 1.25 = 12.5 → 13)

### Карты с фиксированными значениями

- **Контратака:** Блок = 4, Урон = 3 (не зависят от уровня)
- **Ослабляющий щит:** Блок = 4 (фиксированное значение, не зависит от уровня)

## Поток урона и модификаторы

### Исходящий оружейный урон (от игрока/врага)

1. Базовый урон карты/атаки
2. **Модификация Weak:** Если у атакующего есть Weak → урон × 0.75
3. Применение через `dealDamage()`

### Входящий оружейный урон (к игроку/врагу)

1. Урон после модификации Weak (если применимо)
2. **Модификация Vulnerable:** Если у цели есть Vulnerable → урон × 1.5
3. Сначала поглощается блоком
4. Остаток уходит в HP

### Статусный урон (Кровоток)

- Не является оружейным уроном (`isWeaponDamage: false`)
- Проходит через блок полностью
- Наносится в начале хода через `applyBleedIfNeeded()`

## Потенциальные проблемы

### Ослабляющий щит

**Ожидаемое поведение:**
- Слабость +1 на врага
- Блок +4 игроку

**Реальная логика (код):**
```swift
case .weakDefend:
    battle.addStatus(.weak, stacks: 1, to: .enemy)  // ✅ Выполняется
    battle.playerBlock += 4                          // ✅ Выполняется
    pushLog(&battle, side: .player, "...")
```

**Возможные причины, почему эффекты не видны:**
1. UI не отображает статусы врага корректно
2. Статусы применяются, но не учитываются в расчетах урона (проверить `modifiedOutgoingWeaponDamage`)
3. Блок добавляется, но сбрасывается до следующего хода (блок сбрасывается в `endTurn()`)

### Примечание о статусах врагов

**Изменение:** Функция `applyEnemyOnHitStatus()` была удалена. Враги больше не накладывают статусы автоматически при атаке. В будущем враги должны использовать карты из той же базы карт, что и игрок, для применения статусов.
